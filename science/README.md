# 과학 놀이터 (아이패드 오프라인 앱)

초등 3학년 과학 게임 4종을 하나로 묶은 홈 화면 앱(PWA)입니다.
자석 정원 · 꼬마 강 연구소 · 배추흰나비 키우기 · 소리 마을 악단

## 아이패드에 설치하기
1. 이 폴더를 https 주소로 올립니다 (GitHub Pages, Netlify, Cloudflare Pages 등 정적 호스팅이면 됩니다).
2. 아이패드 Safari로 그 주소를 엽니다.
3. 목록 오른쪽 위에 "인터넷 없이 실행 가능"이 뜰 때까지 기다립니다 (약 3.5MB).
4. 공유 단추 → 홈 화면에 추가.
5. 이후로는 홈 화면 아이콘으로 인터넷 없이 실행됩니다. 게임 기록은 기기에 저장됩니다.

주의: 파일 앱에서 html 파일을 직접 여는 방식은 오프라인 저장과 기록이 제대로 동작하지 않습니다.

## 구성
- index.html — 게임 목록 화면
- games/ — 게임 4종 (각각 한 파일, 오른쪽 아래 단추로 목록 복귀)
- font/ — 게임에 쓰인 글자만 담은 글꼴 (SIL Open Font License)
- sw.js — 오프라인 저장. 파일을 바꾼 뒤에는 `python3 tools/make-sw.py`로 다시 만듭니다.
